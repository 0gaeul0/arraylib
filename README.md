
# arraylib

Библиотека для работы с массивами целых чисел на C++17.

## Возможности

- Сумма, минимум и максимум
- Среднее арифметическое и медиана
- Подсчёт положительных чисел, отрицательных чисел и нулей
- Произведение элементов

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
./build/app
```

## Тесты

```bash
ctest --test-dir build --output-on-failure
```

## Вариант 14 — Показания датчиков

Программа обрабатывает показания датчика температуры, определяет
минимальное, максимальное и среднее значения, а также подсчитывает
количество показаний ниже и выше допустимого диапазона 18–25 градусов.
